# 🛒 Mall of Dehradun - Billing System

A simple web-based billing system built using **HTML, CSS, and JavaScript**.  
This project allows users to add products to a cart, view the list of items, and calculate the total bill.

---

## ✨ Features
- Add product name and price to the cart
- Display all items in the cart with numbering
- Show the total bill amount
- Clean and responsive UI with styled components
