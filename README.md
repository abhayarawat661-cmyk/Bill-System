# 🛒 Mall of Dehradun – Billing System

A simple browser-based billing application built using **HTML, CSS, and JavaScript**. It allows users to add products to a shopping cart and calculate the total bill instantly.

## ✨ Features

* ➕ Add products with their names and prices.
* 🛍️ Display all added products in the cart.
* 🔢 Automatically number cart items.
* 💰 Calculate the total bill.
* 🎨 Simple and colorful user interface.
* ⚡ Instant bill calculation using JavaScript.

## 🛠️ Technologies Used

* HTML5 – Structure
* CSS3 – Styling and layout
* JavaScript – Functionality and calculations

## 📂 Project Structure

```text
Bill-System/
│
└── index.html
```

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/abhayarawat661-cmyk/Bill-System.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter a product name and price.

5. Click **ADD TO CART**.

6. Click **SHOW TOTAL BILL** to calculate the bill.

## 📸 Project Preview

Open `index.html` in your browser to see the application.
